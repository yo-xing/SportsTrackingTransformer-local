Predicting NFL Yards Gained with RFID Tracking Data

Executive Summary: Model Comparison and Results

Executive Summary

Using real-time RFID player tracking data, we developed machine learning models to predict yards gained on NFL plays. Our best model, Min+Football, achieves an average prediction error of 4.44 yards—less than half a first down—by tracking the football as a 23rd entity alongside 22 players. The key finding: tracking the football's position provides a 2% improvement over the same features without it, while overloading the model with comprehensive game state features actually hurts performance.

The Problem

NFL RFID tracking systems capture the real-time position and velocity of all 22 players on the field at 10 frames per second. The challenge: predict how many yards will be gained on each play as it unfolds. This is a 110-class classification problem (predicting yards from -10 to +99), with applications in live game analytics, defensive positioning assessment, and play outcome prediction. The difficulty lies in translating fluid, dynamic player movements into accurate yard predictions across diverse game situations.

Our Approach: Four Model Variations

We tested four variations of a Transformer architecture, all trained on the same 18 weeks of NFL data (~2M training samples), differing in feature engineering and entity tracking:

Baseline: 6 features per player, 22 players tracked
→ Test MAE: 4.97 yards

  • Features: position (x_rel, y_rel), velocity (vx, vy), team (side), ball carrier status (is_ball_carrier)
  • Philosophy: Minimal feature engineering, let the model learn from raw spatial data

Minimalist: 7 features per player, 22 players tracked (NO football)
→ Test MAE: 4.53 yards (8.9% improvement)

  • Added Feature: distanceToGoal (field position context)
  • Philosophy: Strategic addition of one critical game state feature

Min+Football (winner): 7 features per entity, 23 entities (22 players + football)
→ Test MAE: 4.44 yards (10.7% improvement over baseline, 2.0% better than Minimalist)

  • Same 7 features as Minimalist BUT tracks football as 23rd entity
  • Philosophy: Track the ball, minimal features, let attention do the rest

Contextual: 11 features per entity, 23 entities (22 players + football)
→ Test MAE: 4.62 yards (7.0% improvement over baseline)

  • Added Features: yardsToGo, down, distanceToGoal, quarter, half_seconds_remaining, plus football tracking
  • Philosophy: Comprehensive game context

Key Insights:

  1. Football tracking helps: Adding the football as a 23rd entity improves performance (4.44 vs 4.53 yards)
  2. More features hurt: Comprehensive game state (11 features) performs worse than minimal approach (7 features)
  3. Let attention learn: The Transformer discovers game context from spatial relationships

Understanding MAE in Football Terms

Mean Absolute Error (MAE) measures the average distance in yards between our prediction and the actual outcome. Think of it as "how many yards off is the model's guess, on average?"

  • Our best model: 4.44 yards → typically within half a first down
  • Minimalist (no football): 4.53 yards → 0.09 yards worse
  • Baseline model: 4.97 yards → about half a yard worse than winner

Performance varies dramatically by situation:

  • Rush plays: 2.97 yards → very accurate (within 9 feet on average)
  • Pass plays: 5.85 yards → more uncertainty (receiver routes, QB decisions)
  • Last 10 frames before tackle: 1.58 yards → pinpoint accuracy (within 5 feet)

For context, being off by 4.44 yards on average means the model usually knows within a few yards where the tackle will occur—valuable for real-time decision-making and post-play analysis.

Best Model Deep Dive: Min+Football

Architecture & Training

Model Specification: Transformer M64_L4

  • 64 hidden dimensions, 4 transformer layers
  • Self-attention mechanism across all 23 entities (22 players + football) simultaneously
  • ~200K trainable parameters

Features (7 per entity):

  • Spatial: x_rel, y_rel (position relative to ball carrier)
  • Velocity: vx, vy (movement direction and speed)
  • Context: side (team: offense/defense/neutral for football), is_ball_carrier (binary), distanceToGoal (field position)

Entities: 23 total

  • 22 players (offense + defense)
  • 1 football (tracked as separate entity with same features)

Training Data: 18 weeks of NFL games

  • Training: 1,994,318 samples
  • Validation: 429,224 samples
  • Test: 433,398 samples

Coordinate System: All positions normalized relative to ball carrier's starting position for consistency across plays

Overall Performance

Test Set Results:

  • MAE: 4.44 yards (10.7% better than baseline, 2.0% better than Minimalist)
  • Exact Accuracy: 17.8% (challenging 110-class problem)
  • Strong Generalization: Train 4.32y → Val 4.34y → Test 4.44y (minimal overfitting)

The model shows consistent performance across all data splits, indicating it learned generalizable patterns rather than memorizing training data.

Why Football Tracking + Minimal Features Works

The Transformer architecture's self-attention mechanism allows it to learn complex spatial relationships directly from player and ball positions. Here's what we learned:

  • Football tracking matters: Adding the football as 23rd entity improved performance by 2.0% (4.44 vs 4.53 yards)
    • The ball's trajectory provides critical information about play outcome
    • Especially valuable in rush plays where ball position tightly correlates with tackle location
  • Strategic beats comprehensive: Adding one game state feature (distanceToGoal) improved baseline by 8.9%
    • Field position provides non-redundant context the model can't infer from positions alone
  • Diminishing returns from more features: Adding 5 game state features (Contextual model) performed 4% worse (4.62 vs 4.44 yards)
    • The attention mechanism already infers down-and-distance, time remaining from formations
    • Additional features add noise rather than signal

Lesson: Track the ball, add minimal strategic context (field position), let the attention mechanism discover game patterns from spatial relationships.

Limitations and Future Directions

Training Data Constraints

Single Season Data: Our models were trained on 18 weeks from a single NFL season. This limitation has several implications:

  • Limited tactical diversity: One season captures only a subset of offensive/defensive schemes, coaching philosophies, and play-calling patterns
  • Team-specific biases: Models may overfit to specific team tendencies present in the training season
  • Rule changes not captured: NFL rules evolve annually; single-season training may not generalize across rule changes
  • Weather and field conditions: Limited variety in environmental factors (indoor vs. outdoor, weather, field types)

Transformer Scaling Potential

Transformers are known to scale exceptionally well with data—a key advantage over traditional architectures:

  • Data-hungry by design: Transformer architectures typically show continued improvement with 10x, 100x, or even 1000x more training data
  • Self-attention learns complex patterns: With more data, the attention mechanism can discover increasingly subtle tactical patterns across diverse game situations
  • Diminishing returns for feature engineering: As data increases, the model's ability to learn from raw positions improves, potentially eliminating the need for even minimal features like distanceToGoal

Expected improvements with multi-season data:

  • Cross-season generalization: Exposure to multiple coaching staffs, player personnel, and meta-game evolution
  • Rare event handling: Better predictions for sacks, trick plays, and unusual formations (currently limited by small sample sizes)
  • Temporal awareness: Learning how strategies evolve within and across seasons
  • Transfer learning potential: Pre-training on multiple seasons could enable rapid adaptation to new seasons with minimal fine-tuning

Realistic performance ceiling: With 5-10 seasons of data (~50-100M training samples), we would expect:

  • Test MAE potentially dropping from 4.44 to 3.5-4.0 yards (10-20% additional improvement)
  • Significantly better performance on rare events (sacks, trick plays)
  • More robust generalization to new teams, coaches, and strategic innovations

The current 4.44-yard result represents what's achievable with limited data and minimal feature engineering. The Transformer architecture's scalability suggests substantial headroom for improvement given more training data.

Implications

These results demonstrate that modern deep learning architectures can extract meaningful predictions from minimally processed player tracking data when the football is tracked. The 4.44-yard accuracy enables practical applications in:

  • In-game analytics: Real-time yard prediction as plays develop
  • Defensive evaluation: Assessing how defensive positioning affects expected outcomes
  • Play design analysis: Understanding which formations and movements correlate with yardage
  • Expected yards models: Benchmarking actual vs. predicted performance
  • Ball tracking emphasis: Results suggest sports analytics should prioritize tracking the ball/puck/object of play, not just players

The finding that tracking the football improves performance while adding more game state features hurts suggests that future work should focus on what entities to track (ball, referees, landmarks) rather than engineering more features. The Transformer's attention mechanism is powerful enough to discover game context from spatial relationships alone.

Investment priority: Given Transformers' scaling properties, organizations should prioritize collecting more seasons of tracking data over manual feature engineering. The architecture will extract more value from additional data than from additional features.
